# zugbase

A private, free shidduch organizer — a personal CRM for guys, girls and shadchanim that keeps
everything on the owner's own phone. Successor of PeerMatch (`shiduchim/match`) and the ZivugBase
experiment (`shiduchim/zivugbase`), which both stay as they are, as references.

Start with **`CLAUDE.md`**, then the documents in `docs/`.

This repository is public: only made-up data ever goes in it.
